Privacy Policy

This policy covers Hermes, a private, single-user application that accesses Google Workspace data through Google's OAuth 2.0 APIs. It has exactly one user: its developer, who is also its owner. No one else can install, access, or use it.

1. What data is accessed

Only after the developer grants consent, and only for the developer's own Google Account, Hermes may access:

  • Gmail — read messages, send messages, and apply labels.
  • Google Calendar — read and manage events on the owner's calendars.
  • Google Drive — read, upload, organise and share the owner's files.
  • Google Sheets and Google Docs — read and write the owner's documents.
  • Google Contacts — read the owner's contact list.

2. How data is used

Accessed data is used solely to carry out tasks the developer requests inside the local application — for example, listing upcoming events, drafting a message, or filling a spreadsheet. It is not mined, profiled, or used for advertising.

3. Storage and transmission

  • Data is processed and stored locally on the developer's own computer.
  • OAuth credentials and access tokens are stored in local files with permissions restricted to the local user account.
  • Hermes operates no remote server and sends no Google user data to any third party, advertiser, or analytics service.
  • The only network traffic is the direct HTTPS conversation with Google APIs.

4. Sharing

Google user data is never sold, rented, transferred, or disclosed to any third party. No human reads it, other than the owner, who is its subject.

5. Retention and deletion

Locally cached data can be deleted at any time from the developer's machine. Access can be revoked immediately at myaccount.google.com/permissions, which invalidates the stored tokens; deleting the local token file has the same effect.

6. Google API Services User Data Policy

Hermes's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

7. Children

Hermes is a private developer tool and is not directed at children under 13.

8. Changes

Any change to this policy will be published on this page with a new date below.
